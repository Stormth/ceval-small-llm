## 建议的错误类型

- **知识不足**：模型不知道事实，或混淆概念。
- **推理错误**：知道相关知识点，但计算/排除过程出错。
- **指令不遵循**：没有按要求的格式输出，或输出多个答案。
- **输出截断**：达到 `max_new_tokens` 仍未收束。
- **答案格式无效**：最后一行没有可提取的唯一选项。
- **改对变错**：基线答对，改进后答错，需要具体展示。

## 记录要求

- 保留完整 `prompt` 和 `raw_output`，不要只写摘要。
- 说明该错误是知识问题、推理问题、格式问题，还是评测协议问题。
- 如果某个改进让题目“改对”或“改错”，在结果分析中单独说明。
